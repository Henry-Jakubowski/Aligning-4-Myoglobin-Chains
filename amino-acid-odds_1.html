What are the odds of drawing S–G–G–S?

Imagine a beaker holding one copy of each of the 20 amino acids, sized here by how often that residue actually turns up in real proteins. Reach in, note which one you grabbed, and drop it back in before reaching again — so every draw sees the same odds. Do that four times. This page simulates exactly that, and calculates the chance those four draws spell out Ser–Gly–Gly–Ser.

The 20 tiles are sized by the background amino-acid frequencies associated with the BLOSUM62 substitution matrix (Henikoff & Henikoff, 1992) — BLOSUM62 itself is a table of pairwise substitution scores, not a frequency table, but its derivation rests on exactly this single-residue frequency distribution, and it's the standard stand-in for "how common is each amino acid in real proteins."

A second way to score the same four letters

Not as an ordered word this time, but as a composition — the mix of letters in a single alignment column, scored against the same BLOSUM62 background used above.

Take the same four letters, S–G–G–S, but stop treating them as a sequence with an order. Just count them: S appears in 2 of the 4 positions (fS = 0.50), and G appears in the other 2 (fG = 0.50). That's exactly the situation at one real alignment column — two species carrying Ser, two carrying Gly. These aren't two routes to the same answer — they score different questions. The box above this one asks how surprising it is to draw this exact ordered string from the background, four letters in a row. This box asks how far this column's composition (50% Ser, 50% Gly, ignoring order entirely) has drifted from what background chance predicts — the same calculation used to score a real alignment column's conservation. A narrower question (match this exact order) always carries more bits than a broader one (match this mix, any order) built from the same letters.
